🐍 Python Basic Information Program
> ✨ A simple beginner-friendly Python project that collects basic user information, demonstrates \*\*data types\*\*, \*\*memory addresses\*\*, \*\*type conversion\*\*, and performs a small calculation.
---
📌 Project Overview
This program asks the user to enter:
👤 Name
🎂 Age
📏 Height in centimeters
🔢 Favourite number
It then displays the entered information along with the data type and memory address of the values.
The program also calculates an approximate birth year using the current year used in the program.
---
🎯 Features
Feature	Description
👋 Welcome message	Introduces the program
📝 User input	Collects name, age, height and favourite number
🔄 Type conversion	Uses `int()` and `float()`
🧮 Calculation	Calculates approximate birth year
🔍 Data types	Displays the type of each value
💾 Memory address	Displays memory address using `id()`
📊 Result display	Shows the user's information clearly
---
🧠 Python Concepts Used
1. `input()`
Used to take information from the user.
2. Type Casting
The program converts input strings into the required data types:
```python
age = int(input("Enter your age: "))
height = float(input("Enter your height in cm: "))
favourite\_number = int(input("Enter your favourite number: "))
```
3. `type()`
Used to display the data type of a value.
4. `id()`
Used to display the memory address associated with a Python object.
5. Variables
The program uses variables such as `name`, `age`, `height`, `favourite\_number`, and `birth\_year`.

▶️ How to Run
Step 1 — Install Python 🐍
Make sure Python is installed on your computer.
Step 2 — Open the project
Open `project1.py` in VS Code, IDLE, PyCharm, or another Python editor.
Step 3 — Run the program
Run:
```bash

```
Step 4 — Enter the requested information
The program will ask for your name, age, height and favourite number.
